# 🌐 Primeiro Projeto — Página Web com HTML5

## 📖 Sobre o projeto

Este é o **primeiro projeto desenvolvido durante os estudos de Desenvolvimento Web**, com foco nos fundamentos do **HTML5**.

O objetivo principal foi compreender como uma página web é estruturada, utilizando elementos HTML para organizar textos, títulos, links, imagens e demais conteúdos.

Este projeto representa a etapa inicial da aprendizagem em desenvolvimento web, servindo como base para os projetos posteriores, que passam a incluir estilização com CSS, responsividade, acessibilidade e outras tecnologias.

---

## 🎯 Objetivos

O projeto foi desenvolvido com os seguintes objetivos:

* Compreender a estrutura básica de uma página HTML;
* Utilizar a declaração `DOCTYPE`;
* Definir o idioma da página;
* Trabalhar com a estrutura `<html>`, `<head>` e `<body>`;
* Utilizar títulos e subtítulos;
* Organizar informações utilizando parágrafos;
* Trabalhar com links;
* Inserir imagens;
* Utilizar atributos HTML;
* Praticar a organização e identação do código.

---

## 🧱 Estrutura HTML

O projeto utiliza a estrutura básica de um documento HTML5:

```html
<!DOCTYPE html>

<html lang="pt-BR">

<head>
    <meta charset="UTF-8">
    <title>Minha Página</title>
</head>

<body>

    <!-- Conteúdo da página -->

</body>

</html>
```

### Principais elementos utilizados

* `<!DOCTYPE html>` — informa que o documento utiliza HTML5;
* `<html>` — elemento raiz do documento;
* `<head>` — contém informações sobre a página;
* `<meta>` — configurações e metadados;
* `<title>` — título apresentado na aba do navegador;
* `<body>` — contém o conteúdo visual da página;
* `<h1>` — título principal;
* `<h2>` e `<h3>` — subtítulos;
* `<p>` — parágrafos;
* `<a>` — links;
* `<img>` — imagens.

## 📚 Conceitos praticados

Durante o desenvolvimento foram trabalhados conceitos fundamentais de HTML:

### Estrutura de documentos

Compreensão da hierarquia dos elementos HTML e da relação entre `head` e `body`.

### Hierarquia de títulos

Utilização de títulos para organizar o conteúdo de acordo com sua importância.

### Textos

Utilização de parágrafos para apresentar informações de forma organizada.

### Links

Criação de links para navegação entre páginas ou acesso a conteúdos externos.

### Imagens

Inserção de imagens utilizando o elemento `<img>` e seus principais atributos.

### Atributos

Prática com atributos como:

```html
lang
charset
href
src
alt
```
